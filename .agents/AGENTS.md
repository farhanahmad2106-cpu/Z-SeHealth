# Z-SeHealth — Agent Mandatory Startup Rules

## ⚠️ CRITICAL: Read These Files FIRST — Every Single Conversation

Before writing a single line of code, making any edit, or answering any question about this project, you MUST read ALL three files below in this exact order. No exceptions.

### 1. Read Project Memory (Current State)
This tells you what has already been built, what is in progress, which files were last modified, known issues, and the full project roadmap. Always read this first so you never re-implement something that already exists.

Read this file: `MEMORY.md`

### 2. Read Project Rules (What to Do & Avoid)
This tells you which libraries to use, which to avoid, the exact AI fallback chain, error handling patterns, design system rules, security requirements, git conventions, and component architecture. Never break these rules.

Read this file: `RULES.md`

### 3. Read Project Features (Roadmap & Scope)
This tells you the full feature list — what was previously built, what was built recently, and what is planned next. Use this to understand scope before adding anything new.

Read this file: `Z-SeHealth_project_features.md`

---

## After Reading, Update MEMORY.md

After completing any work in a session, always update `MEMORY.md`:
- Add a new "Last Session Summary" at the top
- Mark completed features as done
- Update "Last Modified" dates for any files touched
- Add any new API endpoints or MongoDB schema changes
- Log any new known issues or technical debt discovered
